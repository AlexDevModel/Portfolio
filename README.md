# Personal 3D Portfolio

A personal portfolio for showcasing 3D work, game development and creative programming.

## Stack
- React + TypeScript
- Vite
- Three.js via React Three Fiber and Drei

## Run locally
```bash
npm install
npm run dev
```
Then open the local URL printed by Vite (usually http://localhost:5173).

Build for production with `npm run build`.
